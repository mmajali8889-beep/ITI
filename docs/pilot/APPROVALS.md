# موافقات رؤساء الأقسام قبل الإطلاق (30.5)

> **الأسماء افتراضية** (معلَّمة "اسم افتراضي")، وُضعت لتجهيز النموذج. **لا توجد أي موافقة موقّعة بعد.** يُستبدل كل اسم بالاسم الحقيقي، ويوقّع صاحبه بعد مراجعة الأدلة الخاصة بقسمه ونتائج التجربة التشغيلية (30.4).

كل رئيس قسم يوقّع على ثلاثة أمور:

1. راجع الأدلة المذكورة لقسمه.
2. تدرّب فريقه واجتاز الاختبار العملي (30.3).
3. يوافق على تشغيل قسمه بالنظام في المستشفى الأولى.

الإطلاق (30.6) لا يتم إلا بعد اكتمال كل التواقيع.

## الأقسام

### السريري

- **الاسم:** د. سلمى النجار (اسم افتراضي).
- **يراجع:**
  - المراحل الإلزامية الافتراضية لكل مسار في رحلة المريض (27.3)، من Administration → Care Pathways. يعدّلها أو يعتمدها كما هي.
  - قواعد التشخيص والملاحظة الموقّعة قبل إنهاء الزيارة.
  - إقرار النتائج الحرجة.
  - تنبيهات الحساسية.
- **الحالة:** بانتظار التوقيع.

### السجلات الطبية

- **الاسم:** لينا عيسى (اسم افتراضي).
- **يراجع:**
  - دورة السجل: النواقص، الإغلاق، القفل، التعديل المسبب، الأرشفة ومدة الاحتفاظ.
  - إدارة حسابات بوابة المريض (إنشاء، إعادة تعيين، تعطيل) وتسجيلها في التدقيق.
- **الحالة:** بانتظار التوقيع.

### المالية

- **الاسم:** سامر قاسم (اسم افتراضي).
- **يراجع:**
  - قائمة الأسعار والخدمات.
  - الفوترة والدفع.
  - مسار التأمين اليدوي: الأهلية، والمطالبة، وتسجيل نتيجتها. لا يوجد ربط إلكتروني عند الإطلاق (قرار 29.1).
- **الحالة:** بانتظار التوقيع.

### الصيدلية

- **الاسم:** د. هالة منصور (اسم افتراضي).
- **يراجع:**
  - قائمة الأدوية (formulary).
  - التدقيق الإلزامي قبل الصرف.
  - منع الصرف من مخزون غير كافٍ.
  - تنبيه الحساسية.
- **الحالة:** بانتظار التوقيع.

### المختبر

- **الاسم:** فادي يوسف (اسم افتراضي).
- **يراجع:**
  - كتالوج الفحوص والمدى الطبيعي.
  - الاعتماد الفني ثم السريري.
  - رفض العيّنة.
  - النتائج الحرجة.
  - الإدخال اليدوي للنتائج. ربط الأجهزة مؤجّل إلى المرحلة 31.
- **الحالة:** بانتظار التوقيع.

### الأشعة

- **الاسم:** د. مازن الحلبي (اسم افتراضي).
- **يراجع:**
  - منع "الصور متاحة" والتقرير النهائي قبل وصول الدراسة (26.1).
  - حصر العارض في دراسات المستشفى (26.4).
- **ملاحظة:** الأشعة خارج نطاق التجربة الأولى حتى ربط الأجهزة الحقيقية (26.2). يوقّع رئيس الأشعة بعد ربطها وتجربتها.
- **الحالة:** بانتظار التوقيع.

### الأمن وتقنية المعلومات

- **الاسم:** علاء درويش (اسم افتراضي).
- **يراجع:**
  - الصلاحيات حسب الأدوار.
  - قفل الحساب بعد المحاولات الفاشلة.
  - التدقيق الكامل للقراءة والكتابة.
  - HTTPS والأسرار.
  - النسخ الاحتياطي اليومي، ونتيجة تمرين الاستعادة على خادم الإنتاج.
  - المراقبة والتنبيهات.
  - سجلات الحاويات إلى journal النظام.
- **مسألة مفتوحة للقرار:** قراءة سجل التدقيق مسموحة اليوم لأدوار الإدارة فقط. أما دور السجلات الطبية فمسموح له على مستوى المسار (`@Roles`)، لكنه مرفوض على مستوى الصلاحية (`audit` ← `administration`). المطلوب: هل يراجع قسم السجلات الطبية سجل التدقيق؟ إن كان نعم، تُعطى صلاحية صريحة.
- **الحالة:** بانتظار التوقيع.
